# ADR-0001: 保留字幕階段結果並由使用者指定重做

| | |
| --- | --- |
| Status | Accepted |
| Date | 2026-10-20 |
| Deciders | 本次功能規劃的需求提出者、Codex |

本文件記錄已確認的設計決策，功能尚未實作。

## Context

需求提出者希望改善辨識錯誤與無聲幻覺字幕，並對已下載影片執行字幕任務。
使用者需要獨立選擇各階段模型，避免只更新後段文字時再次支付語音辨識費用。

## Decision

字幕任務保留語音活動偵測、語音辨識、原文後矯正與字幕翻譯各階段的結果，以及產生結果時的設定。
原文後矯正與字幕翻譯可以關閉。

使用者指定重做階段，系統只執行該階段。
上游結果更新後，系統保留下游既有結果並提示過期，由使用者決定是否重做。
必要上游結果不存在時，系統告知需要補做的工作，不自動啟動其他付費階段。

## Consequences

Positive: 使用者可以重用辨識結果並控制外部 API 支出。

Negative: 系統需要額外儲存階段結果與設定，並追蹤結果之間的相依關係。
使用者可能持有已過期的翻譯，介面必須清楚標示其狀態。

Neutral: 結果保留數量、清理方式與設定保存細節仍待規劃。

## Alternatives considered

每次重跑完整流程：任務狀態較簡單且各階段結果一致，但會重複執行使用者未指定的工作並增加 API 支出。

上游更新時自動重做下游：可立即取得一致結果，但使用者無法逐次決定是否支出；本功能採明確指定重做的方式。
