# Triage labels

技能使用下列角色與 GitHub 標籤對照。套用標籤時，以本表為準。

| 技能角色 | GitHub 標籤 | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待維護者評估 |
| `needs-info` | `needs-info` | 等待回報者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交由代理執行 |
| `ready-for-human` | `ready-for-human` | 需要人工實作 |
| `wontfix` | `wontfix` | 不予處理 |

調整詞彙時，修改本表並確認 GitHub 上存在對應標籤。
