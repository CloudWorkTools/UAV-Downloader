# 部署版本保護

部署前讀取遠端正在執行的完整映像版本；候選版本必須包含該提交，且必須通過同一提交的 Web CI 與部署程序內的正式映像測試。無法確認目前版本或版本不在本機 Git 歷史時，先查明並取得版本，不得繼續切換。

部署鎖內重新核對執行中的映像仍為檢查時的版本。若不同，停止並重新檢查，保留既有服務及佇列。只有明確需要回滾時，才使用 `--allow-rollback`；這個選項不略過 CI、已知版本檢查或鎖內核對。

檢查線上版本是否包含於最新 `origin/master`。若尚未合併，保留其分支並建立或延續 PR，讓後續工作以包含線上版本的提交為基礎；部署工具會顯示警告。PR 轉為可審查前，依[流程同步政策](flow-docs-sync.md)完成文件、映射與獨立審查。
