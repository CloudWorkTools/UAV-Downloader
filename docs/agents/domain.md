# Domain docs

本專案採 single-context：根目錄的 `GLOSSARY.md` 統一定義術語，`docs/adr/` 記錄架構決策。

## 探索前讀取

代理探索相關領域前，先讀取根目錄的 `GLOSSARY.md`，並讀取 `docs/adr/` 中與任務相關的決策。若根目錄存在 `GLOSSARY-MAP.md`，先依其指引讀取相關領域的術語表。

這些文件尚未存在時，直接繼續工作。待領域建模過程實際釐清術語或決策，再建立對應文件。

## 術語與決策

規格、任務與測試名稱使用術語表定義的名稱。遇到未定義且影響理解的概念，在領域建模時釐清。

提案若與既有 ADR 衝突，明確指出衝突與重新討論的原因；已接受的決策透過新 ADR 修訂或取代。
