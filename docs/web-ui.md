# Web 與 NAS 使用說明

本文件說明 CloudWorkTools 版本的瀏覽器操作與 SMB 儲存。啟動步驟以[專案首頁](../README.md#本機啟動)為準；桌面工具另見 [UAV Browser](uav-browser.md)。

## 瀏覽與選取

搜尋列提供分類、關鍵字搜尋、全選與下載按鈕，控制項高度一致；窄畫面會換行顯示。

「全選」選取目前頁面的影片；全部選取後，按鈕會變成「取消全選」。下載按鈕會顯示已選數量，並將跨頁選取的影片逐一加入佇列。送出期間不能重複送出；失敗項目會保持選取。

## 連接 NAS

NAS 必須提供 SMB 2 或 SMB 3 共享，預設使用 TCP 445。設定表單位於「系統設定」的「NAS / SMB 連線」。

| 欄位 | 填寫方式 |
| --- | --- |
| 下載完成後傳送到 NAS | 啟用後套用至新加入的任務 |
| NAS IP | IPv4，例如 `192.168.1.100` |
| 共享資料夾名稱 | 例如 `video`，不包含 IP 或斜線 |
| 子目錄 | 共享資料夾內已存在的目錄，例如 `UAV`；可留空 |
| 帳號 | 有寫入權限的 NAS 帳號；網域帳號可填 `DOMAIN\user` |
| 密碼 | 第一次須填寫；保存後留空可沿用 |

1. 填寫連線資料。
2. 按「測試連線」。測試會在目標目錄建立並刪除一個暫存檔，確認登入與寫入權限。
3. 啟用傳送開關。
4. 按頁面下方的「儲存設定」。測試成功本身不會保存設定。

關閉傳送開關並儲存，可讓之後加入的任務只儲存至本機。已加入的任務沿用加入時的 NAS 設定，避免執行途中改變目的地。

## 檔案與設定保存

影片先下載至本機，字幕完成後再一併傳送。傳送中的任務顯示「傳送到 NAS 中」，傳送成功後才顯示完成。本機影片與字幕均保留，因此需要同時預留本機與 NAS 容量。

NAS 傳送使用暫存檔，完整寫入後才改成正式檔名。同名正式檔案已存在時不會覆寫，任務會失敗。取消或傳送失敗時會嘗試清除遠端暫存檔；若 NAS 已斷線，可能仍需手動清除 `.uav-*.part`。多檔案傳送中途失敗時，已完成的遠端檔案會保留。

連線設定與加密金鑰存放在 `/config/nas.json` 與 `/config/nas.key`。請將 `/config` 掛載至持久儲存；未設定 `CONFIG_DIR` 時，使用應用程式的使用者資料目錄。服務重啟後可讀取保存的密碼，前端不會收到密碼內容。加密金鑰與設定須一起備份，且都應限制存取權限。

## 連線或傳送失敗

請先確認 IP 與 SMB 服務，再確認共享名稱、子目錄和帳號寫入權限。此介面不會自動建立 NAS 共享或子目錄，也不會修改 NAS 防火牆。

密碼無法解密時，請重新輸入密碼並保存。變更 IP 或帳號也須重新輸入密碼，避免將已保存的密碼交給其他主機或帳號。

測試失敗不會覆蓋已保存的設定。傳送失敗後可先從本機下載目錄取得影片；重新傳送前，請處理 NAS 已存在的同名檔案。

## 本機驗證範圍

已以本機 Samba 伺服器驗證登入、寫入測試、保存後讀取帳密，以及 MP4／繁體中文字幕傳送。個別 NAS 廠牌、休眠喚醒、網路長時間中斷與大型影片傳送仍須在實際環境驗證。
