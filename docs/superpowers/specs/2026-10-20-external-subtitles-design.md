## 1. 預期成果

使用者可以在影匣 Web 選擇已下載影片，針對語音活動偵測、語音辨識、原文後矯正及字幕翻譯分別選用模型服務。四個階段皆可呼叫外部 API，下載主機不必執行模型。

本功能優先改善聽錯及無聲處亂產字幕。後矯正保留原意與時間，翻譯預設要求停用額外思考模式；功能不能只以文字流暢度判定品質。

各階段的結果可重用，使用者能指定重做其中一個階段。系統提示下游結果是否過期，不自動補跑其他階段或改選模型。相關架構決策由 [ADR-0001](../../adr/0001-retain-subtitle-stage-results.md) 與 [ADR-0002](../../adr/0002-external-api-for-every-subtitle-stage.md) 記錄。

本稿的產品規則來自已確認的訪談決策。標為「實作建議」的儲存方式、模組切分與預設值是 Codex 提案，隨本稿一起審閱；不能當成已交付功能。

## 3. 範圍與排除項目

### 3.1 首版範圍

- 以遠端部署的影匣 Web 為主要操作介面。
- 從下載紀錄選影片，包含下載時未啟用字幕的舊紀錄。
- 選擇服務主機可讀的下載目錄、已設定掛載目錄或 NAS 中的影片，支援單支及批次。
- 每個階段可獨立選服務及模型；可保存多組具名模型設定檔。
- 日文是首版品質驗收來源語言，可選原文、繁體中文、英文或既有全部語言模式。
- 後矯正及翻譯可關閉；繁中與英文皆直接由選定原文翻譯。
- 階段結果、設定快照、指定重做、下游過期提示、失敗續跑及人工字幕保護。
- 外部 VAD 預設選 LocalAI；保留明確選用影匣本機 VAD 的方式。

### 3.2 不納入本次新增功能

- 瀏覽器上傳電腦中的影片、桌面版同步改造、燒錄字幕或改寫影片內容。
- 無時間戳 ASR 的強制對齊、說話者分離、聲音描述字幕及其他來源語言的品質承諾。
- 在影匣自動安裝、部署或修改 LocalAI、Ollama、LM Studio 的模型與服務設定。
- 對任意模型格式、任意 HTTP API 或任意模型主機硬體提供通用支援保證。
- 無限制歷史版本、自動切換服務、失敗時自動改成本機模型或自動重做下游。

既有下載器、公開 CLI 與桌面設定保持相容。保留既有服務選項，不因新增預設選項刪除使用者設定。

## 4. 術語與結果關係

領域名詞依[詞彙表](../../../GLOSSARY.md)，包括階段結果、結果版本及過期結果。

| 階段 | 輸入 | 成功結果 | 模型執行方式 |
| --- | --- | --- | --- |
| VAD | 指定影片的音訊 | 以影片時間表示的語音區間 | 外部 VAD API，預設 LocalAI；或使用者明確選擇的本機 VAD |
| ASR | 音訊及選定 VAD 結果 | 原文片段、穩定片段 ID、起訖秒數 | 外部音訊轉錄 API |
| 原文後矯正 | 選定 ASR 結果及相鄰文字 | 相同 ID 與時間邊界的原文文字 | 獨立選用的外部文字 API，可關閉 |
| 字幕翻譯 | 指定的 ASR 原文或矯正原文 | 相同 ID 與時間邊界的目標語言文字 | 獨立選用的外部文字 API，可關閉 |

翻譯結果按目標語言分開保存，重做繁中不重新產生英文。後矯正與翻譯可使用同一模型設定檔，但結果、參數快照與重做範圍各自獨立。

原文後矯正只修正錯字、標點與既有片段內的斷句，不拆合片段、不改時間或語意，也不補出不確定內容。只有文字的矯正不能可靠還原實際音訊，介面提供矯正前後文字對照。

## 5. 模型設定與相容性

### 5.1 設定檔

每組設定檔包含名稱、適用能力、服務類型、base URL、模型名稱、選用的憑證，以及該服務支援的參數。VAD、ASR、後矯正與翻譯分別選用設定檔；URL 與模型名稱可自行填寫。

預設服務類型是 LocalAI，不預填任何真實部署位址，也不固定模型大小。模型主機的 GPU、顯存、RAM 與服務版本尚未確定，不阻擋規格審閱，但會阻擋實際效能與品質驗收。

設定頁依階段顯示必要協定、請求格式、時間單位、輸出結構及支援參數。它也顯示金鑰是否已保存、相容性測試結果，以及未能確認的能力。模型清單探索失敗時仍可手填名稱，不能把列不出模型視為模型必定不存在。

不提供送出後會被默默忽略的參數。服務只允許在模型設定中修改參數時，介面標示「需至模型服務設定」，可改選服務端已配置的模型別名。影匣不自動修改遠端模型 YAML 或模板。

### 5.2 逐階段契約

| 能力 | 首版契約 | 不符合時的行為 |
| --- | --- | --- |
| LocalAI VAD | `POST /v1/vad`，模型名稱與 16 kHz 單聲道 PCM 樣本；回傳合法的秒單位區間 | 告知格式或模型能力不符，不改用 ASR 或文字聊天假裝完成 VAD |
| OpenAI 相容 ASR | `POST /audio/transcriptions`，multipart 音訊、模型、來源語言、`verbose_json` 與 segment 粒度；回傳 `segments` 的 `start/end/text` | 拒絕只有純文字、缺少必要時間戳或時間越界的結果，不執行強制對齊 |
| OpenAI 相容文字 API | Chat Completions 接受字幕片段，回傳可驗證的片段 ID 與文字 | 缺漏、重複、額外 ID 或無法解析的文字不發布 |
| Ollama／LM Studio 專用 HTTP API | 對應服務的文字生成、能力資訊與思考控制 | 使用已實作的適配方式，不將專用欄位直接塞入其他服務請求 |

base URL 是否已含 `/v1` 由服務類型明確處理，不能重複拼接。外部路徑不依賴影匣主機載入任何 VAD、ASR 或文字模型權重；FFmpeg 與檔案前處理仍在影匣執行。

本機 VAD 選項須先確認部署平台有可用 runtime，沒有時明確標示不可用，不影響外部 API 路徑。實作建議：保留既有可用的本機能力，本次不為此另行移植 Windows 模型 runtime；四階段全外部運作是首版必要驗收項。

相容性測試以小型測試音訊或文字確認正確性，執行前說明會呼叫選定服務。測試至少涵蓋有語音、無語音、合法時間、文字 ID 及要求的思考控制。格式測試通過不表示實際影片品質合格。

VAD 與 ASR 分塊傳輸，不將整部長片的 PCM 陣列一次送出。引擎保留每塊原始時間偏移與必要邊界留白，合併邊界區間並消除重複文字；字幕時間不能因移除無聲區段而向前壓縮。

獨立 VAD 結果是可保存及重做的語音區間。ASR 服務內建且不公開結果的 VAD，不能宣稱可代替此獨立階段；若服務另外執行內建 VAD，須在服務相容性說明中揭露其控制限制。

### 5.3 停用額外思考模式

後矯正與翻譯預設要求停用額外思考模式。可選一般指令模型，或由適配器送出該服務與模型支援的關閉控制；使用者也可明確改為允許思考。

「回應不含思考文字」不能當成「已停用思考」的證據。只有隱藏、分離或刪除思考輸出的方式不能標示為已停用。能力資訊、已知模型與模板控制不足時，顯示「未確認」，預設阻止要求停用思考的任務執行。

介面提供改選已確認模型、調整服務端設定後重測，或明確允許思考的操作。不能默默降級，也不能承諾設定快照可凍結遠端模型別名背後的權重或模板。

### 5.4 設定與憑證保存

任務加入佇列時保存服務、模型、參數與能力檢查身分的快照。修改設定檔只影響新任務；未執行任務可明確套用新設定。已執行或部分完成的任務不混用設定，改用新設定需建立新的重做工作。

快照記錄憑證參照，不保存金鑰副本。憑證與服務位址綁定，修改服務位址不得自動帶入另一個服務的金鑰。執行時若參照失效，任務提示重新設定，不自行改用其他憑證。

Web 回應、歷史結果、錯誤與日誌不回傳金鑰；設定讀寫沿用既有驗證與秘密保存方式。新增 Web 憑證保存不直接沿用僅 Windows 可用的 DPAPI。

## 6. 影片入口與字幕任務

### 6.1 新建任務

下載完成後，按既有字幕開關建立字幕工作。使用者也可在下載紀錄中選取已存在影片，或從服務主機已設定的儲存根目錄選檔後批次建立工作。沒有原始下載紀錄的影片同樣可以建立字幕任務，不會被當成新下載。

提交前顯示所選影片、輸出語言、各階段設定檔，以及啟用或關閉的階段。首次建立結果依相依順序執行所需階段；「指定階段重做」是另一個明確操作，不等同於首次完整產生。

檔案選擇限制在已設定的下載、掛載或 NAS 根目錄；不接受越界路徑或藉符號連結跳離根目錄。影片不存在、無讀取權限、儲存離線或檔案已變更時，顯示實際原因，不重新下載影片。

### 6.2 排程與狀態

字幕工作有獨立佇列，下載後自動建立與手動建立的工作共用此佇列。預設同時處理一支影片，下載流程照常進行；使用者可取消及調整尚未執行工作的順序。

任務至少區分等待、執行中、重試等待、等待續跑、完成、失敗與已取消。各階段顯示進度、選用模型、已完成分塊及錯誤；階段是否啟用、是否已有結果及結果是否過期分開顯示。

相同影片同時只允許一個會寫入字幕結果的工作執行，避免不同任務互相覆蓋。重複送出不能重複排入同一個提交，批次提交的逐片錯誤需保留可辨識的狀態。

服務重啟後保留成功片段與工作快照，中斷工作轉為「等待續跑」，不自動再次呼叫模型。取消時停止尚未發出的呼叫，拒絕晚到回應覆蓋新結果；遠端已接收的請求仍可能繼續運算。

### 6.3 重試

同一階段只重試失敗片段，保留已完成片段。實作建議：暫時性網路錯誤、逾時、HTTP 429 與 5xx 最多額外重試兩次；驗證失敗、401/403 或不相容格式直接報錯。逾時及退避參數可由適配器明確設定，不因未知硬體承諾固定完成時間。

重試仍失敗則停止並保留進度，不換服務、模型、參數或執行位置。對沒有冪等機制的服務，逾時重試仍可能造成遠端重複運算；介面不能宣稱只計費一次。

## 7. 指定階段重做與失效規則

開始重做前，顯示選定階段、模型設定快照、輸入結果版本及預期受影響的下游。預設採用最新且未過期的上游；上游已過期時，可先更新上游，或由使用者明確指定現存舊版本。缺少必要輸入時不自動補跑。

| 重做操作 | 執行內容 | 需要提示的下游 |
| --- | --- | --- |
| VAD | 重新產生語音區間 | ASR、矯正及翻譯 |
| ASR | 使用指定 VAD 與音訊重新辨識 | 矯正；直接或間接依賴此 ASR 的翻譯 |
| 後矯正 | 使用指定 ASR 文字重新矯正 | 使用此矯正結果的翻譯 |
| 翻譯 | 使用指定原文重做選定目標語言 | 無；其他目標語言不變 |

上游新版本成功發布後，系統保留舊下游結果並標示過期，不重新呼叫其模型。重做失敗或取消時，原成功版本仍有效，不因一次失敗嘗試而取代或刪除。

使用者明確指定舊結果時，記錄此次選擇與相依版本，並顯示它並非最新來源。完成該工作不會將整條流程標成全部最新。

關閉後矯正時，翻譯輸入是選定的 ASR 原文，不能偷偷使用舊矯正結果。關閉翻譯時不發出翻譯呼叫，但既有翻譯檔與歷史結果保留。

「重做」必須真的執行指定階段，不能被相同設定的快取直接略過。同一工作的重試或中斷續跑可重用已完成片段；新的強制重做工作不直接沿用該階段的舊片段結果。

## 8. 階段資料、保留與字幕發布

### 8.1 保存內容與版本

每個結果包含影片身分、階段、目標語言、結果版本、上游版本、非秘密設定快照，以及分塊完成資訊。ASR 與文字結果保存穩定片段 ID 及影片時間；VAD 保存語音區間，不能以只有最終 SRT 代替所有中間結果。

各階段及各翻譯語言保留最新與上一份成功結果，可查看、比較及選用現存版本。恢復上一份結果不呼叫模型，依新的採用關係標示下游過期。

實作建議：恢復結果時，同時依 ch. 8.3 的輸出選擇與人工保護規則重新發布該階段對應 SRT；VAD 不發布 SRT。發布失敗時顯示「結果已恢復，字幕發布失敗」，保留原檔並允許只重試發布。介面須在恢復前說明這項效果。

實作建議：被下游引用但超出保留數量的舊版本，只保留來源識別與設定摘要，不永久保留完整文字。介面標示其內容已清理，不再提供作為重做輸入；不能因清理而把相關下游誤認為最新。

抽出的音訊是暫存，任務完成、失敗、取消或啟動時回收已無工作持有的暫存。中斷工作保留片段結果與進度，續跑時可重新從原影片抽音訊；影片身分不符時停止續跑。

### 8.2 資料位置與影片身分

實作建議：階段結果與佇列放在服務既有持久化設定目錄下的字幕專用子目錄，以內部 ID 定位；SRT 放在影片旁。新資料須有版本欄位與原子保存，不能因容器替換而消失，也不把額外大型中間檔自動傳到 NAS。

沿用並擴充既有影片身分驗證；路徑相同但檔案大小、時間或既有內容識別不符時，不重用舊結果。內部 ID 不直接使用瀏覽器提供的檔案名稱作為儲存路徑。

### 8.3 SRT 發布

沿用 `.ja.srt`、`.en.srt`、`.zh-TW.srt` 語言命名與旁掛字幕方式，不改寫影片。中間原文永遠可留在結果資料中，但沒有選原文輸出時，不額外發布原文 SRT。

完整任務只在對應結果成功後發布所選語言。指定階段重做只發布該階段可直接產生且被選為輸出的結果；VAD 不發布 SRT。ASR 重做後若啟用了尚未更新的後矯正，不能自動把舊矯正內容當成新原文發布。

原文發布採本次任務選擇的 ASR 或後矯正結果，翻譯發布採指定目標語言結果。其他語言檔與下游檔保持原內容並標示過期；使用者仍可查看或下載舊結果。

任何已手動修改或來源不明的字幕都另存新檔，只有使用者明確選擇替換才覆寫。已確認由影匣產生且未被修改的同語言字幕，成功結果可原子替換；失敗時保留舊檔。

實作建議：需另存時使用含任務內部短 ID 的檔名，已存在就使用不覆寫的新名稱。無語音結果是合法成功結果；完整流程不必呼叫 ASR 或文字模型，可將選定輸出產生成零片段 SRT，仍遵守人工字幕保護。

### 8.4 NAS 與檔案責任

影片存取、旁掛檔發布與 SMB 錯誤處理走既有儲存介面。直接 SMB、掛載路徑及下載後傳送模式均需驗收，不可把虛擬 SMB 路徑當本機 `Path`。

字幕取消、工作移除或歷史清單整理，不刪除影片及人工字幕。NAS 離線或發布失敗時保留成功階段結果，提供只重試寫入／傳送的方式，避免重新呼叫模型。

## 9. 模型與品質驗收

首版只產生可辨識台詞。呼吸、喘息、笑聲、呻吟及背景音樂不自動轉成台詞或聲音描述；同時要防止輕聲真實台詞被過度過濾。這是驗收目標，不代表 VAD 或 ASR 可以保證完全正確分類。

使用同組代表片段比較目前設定與候選設定，至少包含正常對話、輕聲短句、無台詞與背景音樂。先比較 ASR 與 VAD，再測後矯正及翻譯；人工核對音訊與原文，不只評估流暢度。

| 驗收項目 | 記錄方式 | 通過條件 |
| --- | --- | --- |
| 聽錯與漏字 | 固定人工參考文字，記錄日文字元錯誤率及漏句 | 候選在同組片段降低辨識錯誤，且不能以增加漏句換取較少亂字幕 |
| 無聲幻覺字幕 | 記錄無台詞區段產出的錯誤字幕數與時間範圍 | 較目前設定減少，固定純靜音驗收片段不產生文字 |
| 時間軸 | 人工標記片段邊界並記錄字幕偏移 | 無累積壓縮、重複邊界或越出影片的時間；可接受偏移由驗收者在比較前固定 |
| 後矯正保真 | 原文、矯正文字與音訊對照 | 固定驗收樣本不新增台詞或改變意思，ID 與時間邊界不變 |
| 翻譯 | 原文與繁中／英文對照 | 無漏片段、重複 ID 或額外片段；固定樣本無反轉原意 |
| 資源與速度 | 記錄硬體、模型、量化、版本及階段耗時 | 完整記錄供選型，不先承諾未量測的速度或主機規格 |

品質驗收資料由需求提出者／指定驗收者提供合法可用的代表片段並核對參考文字，實作者執行比較並保留去識別紀錄。主機與樣本未確定前，不將候選模型標為品質已通過。

## 11. 遷移與相容

既有單組 ASR 設定與翻譯設定可遷移為具名設定檔，保留原服務位址、模型及秘密。新安裝預設服務選項為 LocalAI；既有安裝不自動改接 LocalAI 或清除原設定。

舊任務及 SRT 沒有完整階段資料時，介面顯示「尚無可重用階段結果」。首版不把不明 SRT 自動匯入成可信 ASR；使用者可保留字幕並明確啟動新的辨識，不能因選擇翻譯重做而偷偷重新辨識。

新增任務欄位有相容預設值，既有下載歷史、未完成下載與取消語意需維持。新增資料格式升級失敗時不覆蓋原檔，回報需要修復的設定或結果。

## 12. 驗證與交付界線

離線契約、引擎、持久化、儲存與 Web 測試依[工作拆分](2026-10-20-external-subtitles-work-breakdown.md)執行。正式映像與實際環境驗證分開記錄，不能用模擬服務通過取代模型效果驗收。

部署與 CI 要求以 [CONTRIBUTING.md](../../../CONTRIBUTING.md#ci-與生產環境驗證) 為準。本機 Docker 只建置或執行短期隔離檢查，不啟動本機常駐服務；遠端部署使用 `python3 scripts/deploy_remote.py`，沿用本機私有部署設定。

實作後交付需附版本、命令、結果與未驗證範圍，並更新 Web 說明與隱去私人資訊的實際版本截圖。真實位址、帳密、影片、模型與私人品質樣本不進 Git。
