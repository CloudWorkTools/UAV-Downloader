# 需求交付狀態

每項已確認需求分別記錄原型、正式實作、CI 與部署證據。原型通過只代表視覺或互動方向獲確認；有正式介面的需求須核對實際頁面，才能標示已部署。需求與規格仍以 GitHub Issues 為主，本頁保存交付證據。

## 使用方式

開始或恢復一項需求時新增或更新一列。交付時逐列對照使用者要求、正式頁面的操作與提交，附上 CI 執行連結及生產驗證範圍。未執行、阻塞及不適用必須明寫；不能以其他列已完成推定整組需求完成。

狀態使用「待處理」、「進行中」、「已驗證」或「不適用」，並附證據。部署工具改善若尚未在下一次正式部署使用，須與唯讀生產檢查分開記錄。
